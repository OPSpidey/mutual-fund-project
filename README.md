# 🌟 Project Overview

The **Bluestock Mutual Fund Analytics Capstone** is a comprehensive data analytics project focused on the **Indian Mutual Fund Industry**. The project combines data engineering, exploratory data analysis, financial analytics, and business intelligence to uncover actionable investment insights.

Starting from raw datasets, an automated analytics pipeline was developed to clean, transform, validate, analyze, and visualize mutual fund performance. The project enables investors and analysts to understand fund performance, SIP trends, AUM growth, category inflows, investor behavior, and overall market dynamics through interactive dashboards and advanced analytics.

---

# 🎯 Project Objectives

✅ Build a complete ETL Pipeline

✅ Clean and validate mutual fund datasets

✅ Perform Exploratory Data Analysis (EDA)

✅ Analyze NAV trends and fund performance

✅ Study SIP inflows and industry growth

✅ Evaluate category-wise investments

✅ Generate investment insights

✅ Build an interactive Power BI Dashboard

---

# 📊 Dataset Used

The project integrates multiple datasets covering different aspects of the mutual fund industry.

| Dataset | Description |
|----------|-------------|
| 📁 Fund Master | Fund metadata, AMFI code, benchmark, expense ratio |
| 📈 NAV History | Historical NAV data (2022–2025) |
| 💰 AUM Data | Assets Under Management by fund houses |
| 🏦 Monthly SIP | Monthly SIP inflows |
| 📊 Category Inflows | Category-wise investment trends |
| 👥 Industry Folios | Investor folio statistics |
| ⭐ Fund Performance | Returns, rankings and performance metrics |
| 🔄 Transactions | Synthetic investor transaction dataset |
